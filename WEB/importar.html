Formato del Excel

Fila 1 = encabezados. Una fila por neumático. El eje y la configuración del vehículo se infieren solos — no hace falta indicarlos.

    Empresa debe ser exactamente uno de: MOVIL BUS, CRUZ DEL SUR, ITTSABUS, CIVA (no distingue mayúsculas/acentos). Placa o número de vehículo: alcanza con una de las dos columnas — si el Excel trae ambas, se usa la placa cuando está llena y si no el número de vehículo. Posición 1–8 (2-4-2) o 1–6 (2-4) — se agrupa por identificador+fecha para saber cuántas hay. Código y medida no son obligatorias pero se recomiendan: código identifica el neumático entre inspecciones, medida define qué umbral RTD/presión usa el servidor (sin medida, se usa el umbral genérico de la empresa).
